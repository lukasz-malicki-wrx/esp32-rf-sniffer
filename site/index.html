ESP32 RF Sniffer & Bridge

Two CC1101 radios (433 + 868 MHz) on one ESP32: decode remotes, keep a history of what was heard and replay it through a serialised transmit queue.

Your browser cannot flash devices - use Chrome or Edge on a desktop. Flashing needs a secure (https) page. Version … · ESP32 (classic)

How it works

  1. Wire the ESP32 to the radios as in the wiring guide.
  2. Connect the ESP32 over USB and press Install firmware (Chrome or Edge, desktop).
  3. When asked, enter your Wi-Fi - it is sent to the device over USB, nothing is stored online.
  4. Open the device's address in a browser: captures, replay buttons and the live log are there.

Good to know

  • This image has no web UI password - it is meant for trying the project on a trusted network. For a permanent install build rf-sniffer.yaml with your own secrets.yaml.
  • Home Assistant / the ESPHome dashboard can adopt the device; the API key is set during adoption, within 15 minutes of power-up.
  • No driver? CP210x or CH340 USB-serial drivers are needed on some systems.
